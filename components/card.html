Card

Cards group one idea on a white surface. There are two: the Information Card for a short block of text, and the Persona Card for a person with a picture.

Card Types

Switch the device to see the layout change. It follows the width of its frame (936px, 810px or 416px), not the window.

Used for: a short block of information under a heading, such as a finding or a summary. It has a small eyebrow label, a title and body text.

Responsive Layouts

Both cards keep the same padding, radius and type on every device. Only the width changes. It follows the column the card sits in.

Padding and radiusInformation Card 20px and 16px. Persona Card 32px and 24px. Unchanged on every device.

To let a card fill a wider column, set max-width: none on it. The max-width in the component CSS is its default size.

Accessibility

  • Structure: each card is an <article> and its title is a real heading. Use the next level under the section heading (for example h3 under an h2), so screen reader users can jump from card to card. The eyebrow "Small title" is a <p>, not a heading.
  • Contrast: Title on white is 14.38:1. Body text (Text/Title) is 14.38:1 and Persona text (Text/Primary) is 21:1. Image label Text/Title on Image/Pink is 6.10:1. All pass WCAG AA.
  • Known failure: the 12px eyebrow in Text/Accent on white is 4.41:1 and does not meet the 4.5:1 minimum. Change the label color before shipping.
  • Images: a photo of a person needs real alt text that describes them in a useful way. A purely decorative image uses alt="". A placeholder box uses role="img" with an aria-label.
  • Not interactive: the cards are not links or buttons, so they are not in the tab order. If a whole card must be clickable, put one link on the title and stretch it over the card with ::after. Don't wrap the card in a link with more links inside. Give it a visible focus outline, 3px solid #272744 with 3px offset (provisional, not in Figma).
  • Reflow and zoom: width is 100% with a max width, so the card shrinks at 320px and never scrolls sideways. Height is never fixed, so text can grow at 200% zoom. Text uses overflow-wrap: break-word for long words.
  • Small text: the Persona description is 14px and the eyebrow is 12px. Don't go smaller, and keep sentences out of the 12px size.
  • Reading order: source order is name, description, image, which matches the visual order.

Do's and Don'ts

✓ Do

  • Use the Information Card for short text and the Persona Card for a person with an image.
  • Put cards on Surface/Page Background so the white stands out.
  • Let the height follow the content.
  • Use a real heading for each card title.
  • Write real alt text for photos.

✕ Don't

  • Don't set a fixed height on a card.
  • Don't put cards inside other cards.
  • Don't use Text/Accent for body text.
  • Don't add shadows or borders. The design uses a plain white surface.
  • Don't put several buttons or links in one card.
