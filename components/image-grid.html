Image Grid

An image grid lays out several pictures in a tidy set of rows. It has four layouts, and each one adapts to desktop, tablet and mobile.

Layouts

Switch the device to see the grid change. It follows the width of its container, not the window.

Anatomy

  1. Grid: a list of images laid out in columns with an even gap.
  2. Image tile: a rounded box. In Figma the tiles are placeholders filled with Image/Orange, Image/Pink, Surface/Card Alt and Surface/Card, in that order.
  3. Label: the placeholder name, Bold 14px, centered. A real tile holds a photo instead.

Accessibility

  • Structure: a grid of images is a list (ul with li), so a screen reader says "list, 4 items" and the user knows how many images there are.
  • Alt text: every photo needs alt text that says what it shows, such as "Home screen of the website". If a caption is shown next to the image, use a <figure> with a <figcaption> and keep the alt short. Purely decorative images use alt="". Placeholder tiles use role="img" with an aria-label.
  • Reading order: the order in the HTML is the reading order. Don't use CSS order to change it. On mobile the 2x2 grid becomes one column, and the order stays Image 1 to Image 4.
  • Contrast: the label Text/Title is 10.06:1 on Image/Orange, 6.10:1 on Image/Pink, 13.29:1 on Surface/Card Alt and 14.38:1 on Surface/Card. All pass. A tile edge needs 3:1 against the page: the white and cream tiles on Off White are about 1.4:1 and 1.3:1, so don't rely on the edge alone to show where an image ends. Real photos fill the tile, which solves this.
  • Text in images: don't put important text inside a picture. If you must, repeat it in the alt text or a caption.
  • Reflow: columns drop from 4 to 2 and from 2 to 1 with the container width, so nothing scrolls sideways at 320px and the layout works at 400% zoom.
  • Interactive tiles: the grid itself is not interactive. If a tile opens a larger image, make it a real <button> or <a> with a name, a 3px solid #272744 focus outline and at least 44 by 44px size (provisional, not in Figma).
  • Loading: set width and height or the aspect ratio so the page doesn't jump while images load, and use loading="lazy" for images below the first screen.

Do's and Don'ts

✓ Do

  • Use the same layout for images that belong together.
  • Crop photos to the tile with object-fit: cover.
  • Keep the gap equal in both directions.
  • Use Two across short when the images are wide, such as website screenshots.
  • Use Four across for tall images, such as phone screens.

✕ Don't

  • Don't stretch an image out of its ratio.
  • Don't mix layouts in one grid.
  • Don't leave out the alt text.
  • Don't set a fixed pixel height on the tiles. Use the aspect ratio.
  • Don't use the Four across layout with more than four images in one row.
