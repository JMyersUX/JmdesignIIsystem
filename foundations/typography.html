Hierarchy in Use

Size and weight rank the content. The page title is the largest, then section headings, then card titles, with body text the quietest. This is the Information Card from the Card page, built only from presets.

Rules

  • Font: Roboto only, weights 300, 400, 500 and 700. Load them from Google Fonts with font-display: swap.
  • Line height: the percent values above are unitless in CSS (120% becomes line-height: 1.2), so they scale with the font size.
  • Tracking: 0% on every preset. The small eyebrow labels inside components add letter-spacing: .96px (0.08em at 12px). That is set by the component, not a preset.
  • Sizes in components: a few components set exact line heights in pixels (for example the Persona Card text is 14px / 22px). Those come straight from Figma and are listed on each component page.
  • Accessibility: use rem or px that still scales when the user zooms to 200%. Never go below 12px. Keep body lines to about 60 characters and use real heading levels (h1 to h3) in order, even when the visual size differs.

Do's and Don'ts

Body text must be easy to read, and every text color must pass WCAG AA (4.5:1 for normal text).

✓ Do

  • Research Findings

    Use the presets. A section heading is Heading 2 and body copy is Paragraph.

    Presets keep size, weight and line height consistent.

  • Keep body text at 16px, regular weight, with a 160% line height and lines no wider than about 60 characters.

    Paragraph, Text/Primary on Surface/Card (21:1).

  • Secondary text uses Text/Secondary and stays readable on the page background.

    Text/Secondary on Surface/Page Background (5.62:1).

✕ Don't

  • Research Findings

    A serif heading above Roboto body text.

    Don't mix in another font. Roboto only.

  • Figure 1. Hard to read at this contrast.

    Hint Grey on Surface/Page Background is 3.51:1. It fails WCAG AA.

  • Research

    Don't add strokes to rescue low-contrast text. Fix the color (Muted Orange on White is 1.43:1).

  • Regular weight in all caps is harder to read

    Don't set all caps in a regular weight. Use sentence case, or a bold preset.
