Color Palette

Eleven primitive colors, and 23 tokens that point at them. Designs and components use the tokens. They never use a primitive directly, so a color can change in one place.

Primitives

The raw palette. Each card lists the tokens that use it.

  • Dark Blue #272744

    Page title bar and footer background, headings and titles, nav text.

    • Surface/Nav
    • Text/Title
    • Control/Background
    • Border/Outline

  • Muted Orange #F2D3AB

    Image placeholders for the cover, phone screens and web screens.

    • Image/Orange

  • Muted Pink #C69FA5

    Image placeholders for the competitive audit and project cards.

    • Image/Pink

  • Light Purple #8B6D9C

    Button hover state.

    • Button/Hover

    Check: Light Purple on White is 4.41:1, just under the 4.5:1 AA minimum for small text. It is fine for large text and for UI shapes (3:1), so do not use it for small text on white.

  • Off White #D9D9D9

    Page background behind every frame.

    • Surface/Page Background

  • Cream #FBF5EF

    Footer text, slide card backgrounds and the circle behind the logo.

    • Surface/Logo Circle
    • Surface/Card Alt
    • Text/On Nav

  • White #FFFFFF

    Nav bar and card backgrounds, page title text and button text.

    • Surface/Card
    • Surface/Input
    • Text/On Button
    • Text/On Dark

  • Black #000000

    Paragraph text.

    • Text/Primary

  • Hint Grey #6B6E8C

    Inactive carousel dots and the divider lines in the Details section.

    • Control/Inactive
    • Border/Divider

    Check: Hint Grey is for dots and divider lines, not text. On Off White it is only 3.51:1.

  • Disabled Grey #565656

    Disabled button fill.

    • Button/Disabled

  • Blue-Purple #494D7E

    Button default fill, secondary text (labels, captions) and the active nav underline.

    • Text/Secondary
    • Button/Default
    • Nav/Active Indicator

Do's and Don'ts

Text needs at least 4.5:1 contrast (WCAG AA), or 3:1 for large text and UI shapes such as the carousel dots.

✓ Do

Use the tokens in the pairings below.

  • Card title14.38:1 · Pass
    Text/Title on Surface/Card
  • Slide text19.41:1 · Pass
    Text/Primary on Surface/Card Alt
  • Caption5.62:1 · Pass
    Text/Secondary on Surface/Page Background
  • ›13.29:1 · Pass
    Text/On Nav on Control/Background (carousel arrows)
  • Image 110.06:1 · Pass
    Text/Title on Image/Orange

✕ Don't

Don't use pairs that fail WCAG, even when they look close.

  • Placeholder3.51:1 · Fail
    Control/Inactive used as text on Surface/Page Background
  • Button4.41:1 · Fail at 14px
    Text/On Button on Button/Hover
  • Orange text1.43:1 · Fail
    Image/Orange used as text color. Image tokens are fills only.
  • Footer2.90:1 · Fail
    Control/Inactive used as text on Surface/Nav
